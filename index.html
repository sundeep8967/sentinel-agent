⚙️ Dual Execution Architecture

SentinelAgent is designed for resilient judging pipelines:

  • ⚡ Deterministic Heuristic Mode (Default): Guaranteed 100% offline reproducibility for judges without requiring external API keys.
  • 🤖 LLM Mode (Optional): Activates when OPENAI_API_KEY is supplied; provider output is validated before use.
  • 🛡️ Bounded local tools: Confines file paths and caps pytest time; it is not a hardened container boundary.
